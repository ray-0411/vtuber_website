ABOUT THIS PROJECT

關於 Live Observatory

記錄台灣 VTuber 的直播活動與觀看趨勢，讓不同平台、Group 與成員的歷史資料更容易被看見。

INTRODUCTION

網站介紹

Live Observatory 整理台灣 VTuber 在 YouTube 與 Twitch 的直播資料，提供即時直播、觀看排行、Group 與成員分析，以及歷史直播紀錄。

DATA

資料來源

資料由自動化抓取器定期收集，再經過合併、清理與統計後更新至網站。觀眾數與直播資訊可能因平台回報時間而有些微延遲。

METHODOLOGY

統計方式

平均觀眾排行會排除快照數過少的直播；不同頁面使用的統計期間與最低快照條件，會依功能需求調整。

UPDATE

更新與聯絡

網站資料會配合抓取器資料不定期更新；若發現名稱、Group、直播紀錄或統計結果有誤，可透過專案頁面回報。
